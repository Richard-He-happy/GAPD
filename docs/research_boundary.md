# Research boundary

The public GAPD package is intentionally not the research implementation.

While the associated work remains unpublished, the public repository exposes only the aggregate benchmark snapshot shown in the README. Research-specific algorithms and implementation details, parameters and experimental configurations, real molecular targets, candidate data, detailed/raw results, and raw research data remain private.

The public implementation is independent and contains only generic, demonstrative mechanisms. It is intentionally separated from the unpublished research implementation and is not intended to reproduce or reveal it.
